# Database Helper Scripts

Thư mục này chứa các scripts tiện ích quản lý database:

- `backup`: Hỗ trợ sao lưu cơ sở dữ liệu định kỳ hoặc thủ công trước release.
- `restore`: Khôi phục database từ file backup.
- `reset`: Reset toàn bộ database về trạng thái ban đầu và nạp lại seeds.
- `check_health`: Kiểm tra kết nối và độ trễ tới database.
